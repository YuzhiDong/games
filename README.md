# Daisy 的小游戏乐园

在线玩：https://yuzhidong.github.io/games/

- [Daisy 的磁力片王国](https://yuzhidong.github.io/games/tiles/)：拼磁力片闯关，有晓晓配音
- [萌宠黑白棋](https://yuzhidong.github.io/games/reversi/)：熊猫和兔子下黑白棋，三档电脑对手
- [小动物数独](https://yuzhidong.github.io/games/sudoku/)：Daisy 的动物拼布床，入门数独
- [认汉字翻翻乐](https://yuzhidong.github.io/games/fanfan/)：翻牌配对，边玩边认字
- [小火车数数](https://yuzhidong.github.io/games/train/)：把小动物送上火车，10 关学数数
- [小蜜蜂回家](https://yuzhidong.github.io/games/flappy/)：点一下飞起来，帮小蜜蜂穿过花丛
- [小动物回家](https://yuzhidong.github.io/games/maze/)：走迷宫捡星星，12 关送小伙伴回家
- [菜园保卫战](https://yuzhidong.github.io/games/whack-a-mole/)：打地鼠，保护菜园里的蔬菜

每个游戏都是单文件网页，无需联网依赖，手机和电脑都能玩。
