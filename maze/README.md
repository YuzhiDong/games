# 小动物回家 · 迷宫

一个纯前端的绘本风小迷宫游戏。选一只小动物，走过 12 个越来越大的迷宫，捡起星星，把它送回家。

## 玩法

1. 在主页选一只小伙伴（小兔、小猫、小狗、熊猫），点「开始玩」。
2. 在选关页选择已解锁的关卡；通关后解锁下一关。
3. 用方向键、键盘方向键 / WASD，或在迷宫上滑动，带小动物移动。
4. 路上捡星星：捡到的星星越多，过关评价越高（最多 3 颗星）。
5. 点「提示」会高亮接下来三步；也可以按 `H`。
6. 走到终点小屋即过关。12 关全部完成后，过关页停留 3 秒会弹出全通关庆祝页。

进度和选中的小动物会保存在浏览器本地。右上角按钮可以开关音效。

## 文件结构

```
maze-game/
├── index.html         页面结构、内联 SVG 素材（无外部图片）
├── style.css          绘本风样式、动画与各尺寸适配
├── js/
│   ├── game.js        游戏流程、渲染、输入、存档、音效
│   ├── levels.js      12 关的关卡表与确定性生成
│   ├── maze.js        迷宫生成与寻路
│   └── rng.js         可复现的随机数
├── fonts/             本地字体（无外部请求）
└── tests/
    └── verify.mjs     迷宫与关卡数据验收脚本
```

直接用浏览器打开 `index.html` 即可游玩（建议通过任意静态文件服务器访问，以便 ES Module 正常加载）。

## 测试

```bash
node tests/verify.mjs
```

脚本会检查 12 关的关卡表、起终点可达、迷宫确定性、完美迷宫性质、星星数量与可达性等。全部通过时输出 `全部 12 关通过 ✅`。
